# Erklärung der Test-Dateien

**test.bmp** ist eine Ausgangs-Datei, die ein bestimmtes Verhalten prüfen soll.

**test_correct_emboss.bmp** ist die gewünschte Ausgabe, wenn der *emboss*-Filter richtig angewendet wurde.

**test_incorrect_emboss_1.bmp** und **test_incorrect_emboss_2.bmp** sind beispielhafte *nicht gewünschte* Ausgaben, wenn der *emboss*-Filter falsch angewendet wurde.


Es wird hier nur **ein** bestimmtes Verhalten betrachtet und es ist daher keine Zusicherung, dass Ihr gesamtes Programm korrekt ist.
